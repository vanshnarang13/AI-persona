# Bio — Vansh Narang

My name is Vansh Narang. I am an upcoming final year B.Tech student in Biosciences and Bioengineering at IIT Roorkee, graduating in 2027. My current CGPA is 8.009. My work is in production AI systems, specifically LLMs, agentic pipelines, and applied machine learning. 

I got into AI by building, not through coursework. Every project on my resume was self-directed. ## What I Have Built

On the agentic systems side, I built AtlasRAG, a full-stack RAG platform where users upload their own documents and ask questions. The platform handles multimodal ingestion (PDFs, DOCX files, URLs), runs async Celery workers for background processing, supports four configurable retrieval strategies including hybrid vector plus BM25 with RRF, and uses LangGraph for agent orchestration with guardrails and citation tracking. It is a real product with auth, a Next.js frontend, AWS S3 for file storage, and a proper database schema, not a demo notebook.

I also built TradeSmith, an autonomous multi-agent system where four AI agents model legendary investors and independently research and trade equities. Each agent has its own persistent memory, runs on a different LLM (GPT, DeepSeek, Gemini, Grok), and interacts with the world exclusively through typed MCP tools. The system runs on a scheduler and produces a live Gradio dashboard showing portfolio values and trade history.

On the research side, I interned at Noos Technologies for three months doing deep learning research on image steganography. I implemented HiDDeN, SteganoGAN, and CAISFormer from their original papers, built full training pipelines from scratch, and ran systematic trade-off analysis across payload capacity, robustness under compression, and visual fidelity using PSNR and SSIM metrics.

I have also worked on multimodal ML problems including a property price prediction system that fuses satellite imagery with tabular housing data, a drone audio classification system with a multi-task CNN, and NLP-driven trading signal generation using sentiment analysis.
